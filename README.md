# Smart Traffic Light Controller

## Overview

This project was developed during the Microcontroller course using STM32 and STM32CubeIDE.

The system controls traffic light sequencing using programmed timing logic and demonstrates embedded system programming concepts.

## Features

- Traffic Light Sequencing
- Embedded C Programming
- STM32 Peripheral Control
- Timing Logic Implementation
- State Machine Based Control

## Hardware Used

- STM32 Development Board
- LEDs
- Push Buttons
- Power Supply

## Software Used

- STM32CubeIDE
- Embedded C

## Learning Outcomes

- Embedded System Development
- Microcontroller Programming
- Hardware Interfacing
- Debugging and Testing
